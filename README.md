# رحيق RAHEEQ — منصة تسجيل أولياء الأمور

موقع عربي RTL متكامل لتسجيل أولياء الأمور في مدرسة رحيق، بملف HTML واحد بدون خادم خلفي.

## التشغيل

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## الملفات

| المسار | الوصف |
|---|---|
| `index.html` | الموقع كاملاً (HTML + CSS + JS) |
| `assets/logo-emblem.png` | شعار رحيق (حبر شفاف) |
| `assets/logo-lockup.png` | الشعار مع الاسم |
| `assets/favicon.png` / `favicon.ico` | أيقونة التبويب |
| `sounds/*.wav` | المؤثرات الصوتية (تُحمَّل من `sounds/` مع بديل توليدي عبر Web Audio API) |

## أبرز الميزات

- أنميشن افتتاحية: ظهور تدريجي للوجو → انفجار في منتصف الشاشة → ظهور الموقع
- نموذج تسجيل 3 خطوات (ولي الأمر / الطالب / المستندات) مع شريط تقدم
- تحقق كامل: الرقم القومي 14 رقم، الموبايل 11، البريد يحتوي `@`، كلمة السر 6+ ومتطابقة، موافقة الشروط
- أصوات Web Audio API (بدون مكتبات) + زر تشغيل/إيقاف محفوظ في LocalStorage
- شاشة نجاح مع احتفال (كونفيتي) ورقم طلب `RHQ-1234`
- إرسال بيانات التسجيل عبر واتساب إلى `01151947735`
- حفظ المستخدمين في LocalStorage لتسجيل الدخول لاحقاً
- بطاقة عرض تفاعلية (تنقلب) + قسم قيمنا: ثقة، نمو، رعاية، تميز
- متجاوب كاملاً مع الهاتفيين والأجهزة اللوحية وسطح المكتب
